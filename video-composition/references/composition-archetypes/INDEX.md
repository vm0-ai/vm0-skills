# this system Composition Archetypes

These twelve cards are visual composition evidence for national updates, policy briefings, institutional news, and public-service information. Select the content relationship first from [the forty-recipe layout catalog](../LAYOUT-CATALOG.md), then open only the one or two archetypes that can supply useful this system visual grammar. These cards are not a storyboard, required sequence, fixed scene count, taxonomy, or slot library. The first two frames are the approved Style Master pair; the remaining ten prove controlled expansion.

## Selection principles

- Start from the supplied message, not from this menu.
- Do not scan all twelve frames by default. Arrive with one selected content-form recipe, then choose one primary visual reference.
- Choose a card only when its spatial relationship clarifies the message.
- Preserve institutional navy field, white decision surface, blue composition block, amber deadline signal as identity anchors without repeating all of them in every scene.
- Search HyperFrames in English for the required text, chart, media, diagram, or effect behavior.
- Resolve final geometry with real content in a static frame before animation.
- Create a new arrangement when these examples fit poorly.

## Shared release rules

- Keep essential type, data, media, presenter silhouette, face, hands, and connectors disjoint.
- Keep `.presenter-media` replaceable by transparent video.
- Presenter media prefers the standard-size `full` treatment. If it does not fit, use a soft-fade `head-shoulders` crop grounded in a bottom safe corner, move the person to a divider, or omit it; never shrink the full person.
- Use labels for source, meaning, place, time, evidence, category, or state.
- Long content triggers recomposition or another scene before typography becomes too small.
